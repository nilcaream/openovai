# faster-whisper needs to load and transcribe, each at one exact version, installed with --no-deps
# --only-binary=:all: so nothing is resolved at install time and no package runs code while it
# installs. Chosen and tested when a release is cut, like lib/RUNTIME; a change here installs anew
# (KEY). Wheels exist for Linux x86_64 and aarch64 and macOS arm64 and x86_64 on CPython 3.13.
#
# Every wheel is pinned by its sha256 too, and installed with --require-hashes: a wheel whose sum is
# not on its line is refused, whatever PyPI serves. A line lists every wheel of its version pip may
# pick on those platforms, macOS versions included; tests/measure/voice-wheel-hashes.mjs prints
# the lines from PyPI for whoever moves a pin.
