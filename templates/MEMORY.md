# What this workspace has learned

Every session here reads this file before it is asked anything, and everything else a session
holds ends with its conversation. So this is where a fact goes when the next person to sit down
would otherwise work it out again: how something here works, a trap that cost somebody an
afternoon, a decision already taken and the argument that took it.

Keep this file short. It is an index, and it is carried by every session in the workspace whether
or not it needs today's entry. One line per thing known, pointing at a file beside it that holds
the whole of it — so reading the index costs a sentence and reading a fact costs only the sessions
that want it.

Write what was measured, and say what it assumes. A fact nobody can check is one the next session
has to work out again anyway.
